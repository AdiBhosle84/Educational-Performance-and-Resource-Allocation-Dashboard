# 🎓 Educational Performance and Resource Allocation Dashboard

A professional **Power BI dashboard** developed as part of the **CodeAlpha Data Analytics Internship (Task 4)**. This dashboard helps educational institutions evaluate student academic performance and optimize resource allocation using interactive data visualizations and key performance indicators.

---

## 📌 Objective

The goal of this project is to analyze **student performance metrics** and **resource utilization** to support data-driven decision-making in educational institutions.

The dashboard enables administrators, teachers, and management teams to monitor academic outcomes, identify resource gaps, and improve institutional performance.

---

## ✨ Dashboard Features

* 📊 Student Performance Overview
* 🎯 Subject-wise Performance Analysis
* 🏫 Department/Class Performance Comparison
* 📈 Attendance and Academic Trend Analysis
* 👨‍🎓 Student Demographics Insights
* 📚 Resource Allocation Monitoring
* ⚠️ Identify Resource Usage Gaps
* 🎛️ Interactive Filters and Slicers

---

## 📊 Key Performance Indicators (KPIs)

* Total Students
* Average Academic Score
* Attendance Percentage
* Pass vs Fail Rate
* Subject-wise Average Marks
* Resource Utilization Percentage
* Performance by Department/Class
